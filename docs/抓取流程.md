# eAIP 全国数据抓取流程（下个周期照做）

站点：https://www.eaipchina.cn （需账号）。下列接口全部走 `/eaip` 前缀。

一次抓取即可覆盖全国：机场 AD 2 数据 82 份 + ENR 两份（进近区、区调扇区），
再用 `build/gen-national.js` 合成 `data/CN.json`。

## 1. 登录

```js
// 1) 取验证码（必须带 Referer/Origin，否则服务端返回 service request failed）
const id = crypto.randomUUID();
GET /eaip/login/captcha?captchaId=<id>     // 返回 JPEG，4 位字符，人工/视觉识别
// 2) 密码 RSA 加密，公钥硬编码在前端 js/index.*.js 里（搜索 MIGfMA0GCSq...）
password = base64(RSA_PKCS1v15(password))  // PKCS#1 v1.5 填充
// 3) 登录
POST /eaip/login/login {"username","password","captcha","captchaId"}
// -> {retCode:200, data:{token, eaipUserUuid}}；之后所有请求带 header token: <token>
```

token 存到 `~/work/eaip/session.json`，后续脚本复用。

## 2. 找到当前数据包

```js
POST /eaip/package/listPage
{ "conditionList":[{"fieldName":"dataType","paramValue":"BASELINE","expressionType":"EQ"},
                   {"fieldName":"publish","paramValue":"1","expressionType":"EQ"}],
  "pageNumber":1,"pageSize":100,"sortList":[{"fieldName":"publishTime","sortType":"DESC"}] }
// dataStatus: CURRENTLY_ISSUE / NEXT_ISSUE / EXPIRED
// 取 filePath，例如 packageFile\BASELINE\2026-12\EAIP2026-12.V1.3
// effectiveTime/deadline 是 UTC，换算北京时间要 +8h
```

## 3. 取目录树

```
GET /eaip/packageFile/BASELINE/2026-12/EAIP2026-12.V1.3/JsonPath/AIP.JSON
```

3 MB 的扁平数组（不是树形嵌套，用 `pId` 连），每个节点有 `name`、`name_cn`、
`htmlPath`、`pdfPath`（`airporticao` 字段实际为 null，别用）。

机场根节点形如 `ZBYN-TAIYUAN/Wusu`，其子节点 `AD 2.18 …` 的 `htmlPath`
里 `jsId=...` 就是该机场整份 AD 数据的文件名。筛掉 `ZBAA-0G-1:APDC`
这类航图/航路点子节点（名字里带 `:` 或 `-0G-`/`-0W-`）。

## 4. 批量抓机场 AD 2 数据（82 份）

```
GET /eaip/packageFile/<filePath>/Terminal/<ICAO>/<jsId>.js
```

返回 `var AD_AIP = { AD_2_1: {...}, … AD_2_24: {...} }`：
- `AD_2_1` 机场名称/IATA/ICAO
- `AD_2_2` ARP 坐标、标高、磁差（坐标是文本，DDMMSS 或 DD°MM′SS″）
- `AD_2_12` 跑道
- `AD_2_17` ATS 空域（塔台区边界在 `noteLateralLimit` **文本**里，不在 `lateralLimit`）
- `AD_2_18` 通信设施（`designation`/`callSignCn`/`frequencyPrimary`/`frequencyAlternate`/`workTime`）
- `AD_2_19` 导航设施（`designator`/`type`/`frequency`/`latitude`/`longitude`/`location`）

脚本：`node dl_ad.js`（读写 `ad/list.txt`，已下载的跳过，4 并发）。

## 5. 取 ENR（进近区 / 区调扇区）

```
GET /eaip/packageFile/<filePath>/GeneralDoc/<jsId>.js   # 或 .json
```

- `APPAREA`（ENR 2.1.5）→ 进近区。**父节点**「XX进近」通常没有频率，
  **子节点** `AP01(东)`、`AP02` 等才有 `serviceVO.radioChannel.list` 主备频率。
- `CTAAREA`（ENR 2.1.3）→ 区调扇区，每扇区 `serviceVO.radioChannel.list` 带主/备频率，
  `unitProvidingCn` 才是实际值守单位（如「太原区域管制室」）。

## 6. 生成与打包

```bash
node build/gen-national.js   # ~/work/eaip 原始数据 -> data/CN.json
node build/preview.js        # -> docs/preview.svg
node build/build.js          # src/index.html + data/CN.json -> 单文件 HTML（docs/downloads/apk assets）
bash apk/build.sh            # 出 APK，再 cp 到 downloads/
```

## 注意

- 频率以 AIP 文本为准，公共站点（SkyVector 等）常滞后多个周期，且没有扇区级频率。
- 同一 `callSignCn` 下可有多个扇区，`unitProvidingCn` 才是实际值守单位。
- 进近区归属别只看 ICAO 前缀：浦东/虹桥共用上海进近，用「点在多边形内」判断。
- `frequencyAlternate` 偶尔是语言（如 `Chinese`）而非频率，要按数字过滤。
- **侧限里的 `National Boundaries` 是文字，不是坐标**：直接丢掉会把多边形拉成直线、
  扇区画到境外去。生成器会用 `data/border.json`（Natural Earth 1:10m 中国国界简化，
  由 `node build/make-border.js` 从 `~/chn10.json` 生成）把国界折线补进这两个顶点之间。
  中间出现跑道构型之类的标签（`RWY01L/... in use at ZBAA:`）则说明那是**另一段侧限**，
  要拆成多个环，不能混成一个多边形。
- ENR 2.1.1 的情报区（FIR）混在 APPAREA 返回里，别当进近区，单独放 `fir` 图层。
- 图表 PDF 里也有，但 HTML/JS 数据更省事且可解析。

## 7. 跑道 / ILS / 塔台频率总表

```bash
node build/gen-rwy-table.js            # 读 ~/work/eaip/ad/*.js
# -> data/AIRPORT_RWY.json
# -> ~/全国机场跑道与频率.csv   （UTF-8 BOM，Excel 直接开）
# -> ~/全国机场跑道与频率.html  （单文件可搜索，node build/serve-rwy.js 预览）
```

字段对应关系：

- **跑道**：`AD_2_12.runwayDirectionCharacter.list[]`，取 `designator`（13L）、
  `magneticBearing`（133° MAG）、`trueBearing`（126.99° GEO）、`nominalLenWid`、`runWaySurface[].composition/pcn`。
- **ILS**：`AD_2_19.list[]`，按 `collocationGroup` 把 LOC/GP/DME 归成一套，
  跑道端用 `runwayDirectionDesignator`；LOC 频率即 ILS 频率，类别从 `nameCn` 的 `ILS CAT I/II/III` 取。
- **塔台/地面/放行/通播/进近**：`AD_2_18.list[]` 的 `designation` + `frequencyPrimary/Alternate`，
  `note` 里常写「for RWY18R/36L」，同一机场多套塔台按跑道分频时全部保留。

当前数据包只有 83 个机场（82 个有 AD 2 + 和田 ZWTN 只有航图），
珠海 ZGSD 等国内机场不在 AIP 里（AIP 只收对外开放机场），全量需要 NAIP。
