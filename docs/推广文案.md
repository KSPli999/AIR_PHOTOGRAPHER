## 3. 长版（小红书 / 公众号 / 知乎）

**给拍机人的一张空管频率地图｜天际电波 SKYWAVE**

举起相机前，你知道该守哪个波道吗？

起落航线、进近排序、区调移交——每一种场景对应不同频率，而这些数字散落在 AIP 的几百页表格里。天际电波做的事情很简单：**把频率按它所属的空域，重新画回地图上**。

🔹 全国 82 个机场（eAIP AD 2.18 通信设施）
🔹 300 个区调扇区 · 280 个进近扇区/APxx 扇区
🔹 塔台 / 地面 / 放行 / 机坪 / 通播 / 进近 / 区调，主用与备用频率都标
🔹 叠层扇区按高度自上而下排列，放大后直接看得到"哪个高度听哪个波道"
🔹 高倍率下画出跑道、跑道号、ILS 与塔台/地面频率，是示意图形
🔹 完全离线，单文件，不联网、不收集任何数据

**适合谁**
· 拍机 / 观景台的航空爱好者
· 模拟飞行玩家（含 eAIP 周期对照）
· 想弄明白"这架飞机现在跟谁说话"的人

**怎么用**
打开就是全国视角 → 点机场看本场频率 → 双击/双指放大到道面 → 区调、进近的标注会跟着倍率出现。

## 4. 技术版（拍机群 / 论坛 / GitHub README）

**SKYWAVE 天际电波** — 中国空管频率的离线可视化。

· 数据：中国民航公开 eAIP（AD 2.18 通信设施 / AD 2.17 ATS 空域 / ENR 2.1.3 区调 / ENR 2.1.5 进近）
· 规模：82 个机场、748 条机场通信频率、300 个区调扇区（606 条主备）、326 个进近区（280 个带频率）
· 实现：单文件 HTML + 内联 SVG，WebView 壳，零依赖、纯离线；投影为等距圆柱（按纬度取 cos 修正）
· 标注：频率只出现在所属多边形内，按优先级做避让；叠层扇区合并成一块，按高度上界排序；放大到道面尺度时只保留边界线、照常显示频率
· 构建：aapt + javac + d8 + apksigner，全部在本机完成

DEMO 版 APK 与单文件 HTML 同源同数据。示意图，非航图。
