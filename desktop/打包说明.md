# 山西/太原空域频率图 · 桌面版说明

## 一、先说结论：exe 怎么来

这台机器是安卓，没有 Windows 编译工具链（mingw/clang 交叉编译、wine 都没有），
**在这里无法直接产出 .exe**。所以分成两条路：

| 方案 | 需要什么 | 体验 |
|---|---|---|
| A. 单文件 HTML | 无（双击即开） | 浏览器里全屏用，功能与 exe 版完全一致 |
| B. 真 .exe | 一台装了 Node.js 的 Windows 电脑，跑一次 `build-exe.bat` | 双击弹黑窗+自动开浏览器，可放桌面/发给别人 |

B 的本质是 Node.js 官方 SEA（Single Executable Application）：把 `app.js` 塞进
`node.exe` 的副本里，得到的还是合法 PE 文件，不装 Node 也能跑。

## 二、方案 A：单文件 HTML

文件：`dist/太原空域频率图.html`（约 53 KB，数据已内嵌，纯离线，无外链）

双击即可。若系统问「用什么打开」，选 Edge / Chrome。
手机上也能用（微信里发给自己 → 用浏览器打开）。

## 三、方案 B：在 Windows 上出 exe（约 2 分钟）

1. 把 `desktop/` 整个目录拷到 Windows。
2. 把 `dist/太原空域频率图.html` 复制进 `desktop/`，**改名 `app.html`**。
3. 双击 `build-exe.bat`。
4. 得到 `山西空域频率图.exe`。

`build-exe.bat` 做了四件事：生成 SEA blob → 复制 node.exe → postject 注入 → 清理。
第一次运行会联网 `npx postject`（几 MB）。若公司网络限制 npm，可先
`npm i -g postject` 再重跑。

手动版（想自己控制细节时）：

```bat
node --experimental-sea-config sea-config.json
copy "C:\Program Files\nodejs\node.exe" 山西空域频率图.exe
npx postject 山西空域频率图.exe NODE_SEA_BLOB sea-prep.blob --sentinel-fuse NODE_SEA_FUSE_fce680ab2cc467b6e072b8b5df1996b2
```

exe 运行后在 `http://127.0.0.1:3110` 起本地服务并自动开浏览器；关掉黑窗口即退出。
端口被占用时：`set PORT=3410` 再运行。

## 四、以后怎么「拓展地图」

三种粒度，按需要选：

### 1）加一个机场/空域（不改代码）
把新的数据 JSON 丢进 exe 同目录的 `data/` 里（如 `data/ZBSJ.json`），
重新打开程序，页面顶部下拉框就能切换。也可以直接在页面上点「导入数据」选 JSON，
导入的包会存进浏览器 localStorage，下次自动带出来。

### 2）改数据（不碰界面）
数据 JSON 结构（与 `data.json` 同构，最小可用见下）：

```json
{
  "site":  { "id": "ZBSJ", "nameCn": "石家庄/正定", "nameEn": "SHIJIAZHUANG" },
  "meta":  { "cycle": "EAIP 2026-12", "effective": "2026-11-26" },
  "arp":   [38.2807, 114.6964],
  "arpText": "N38°16.8′ E114°41.8′",
  "comms": [ { "type": "TWR", "cn": "石家庄塔台", "f": "118.35", "alt": "124.75", "time": "H24" } ],
  "navs":  [ { "id": "SJW", "type": "VOR/DME", "f": "117.7", "lat": "N38°16.9′", "lon": "E114°41.6′" } ],
  "tma":   { "nameCn": "石家庄进近", "vertical": "GND – 5100 m", "pts": [[38.1,114.2],[38.6,114.9]] },
  "ctr":   [ { "nameCn": "塔台管制区", "vertical": "SFC–1500 m", "pts": [[...]] } ],
  "sectors": [ { "nameEn": "AR07", "unit": "北京区域管制中心", "call": "北京区域",
                 "freqs": [ { "rank": "PRIMARY", "f": "127.7" }, { "rank": "ALTERNATE", "f": "120.7" } ],
                 "vertical": "12500 m–GND", "pts": [[...]], "tyn": false } ],
  "runways": [ { "d": "15/33", "dim": "3400×45" } ],
  "points": [ { "name": "某NDB", "lat": 38.2, "lon": 114.5, "freq": "380", "kind": "NDB" } ]
}
```

`pts` 一律 `[纬度, 经度]` 十进制度；`tyn: true` 的扇区会用高亮色并常显标注。

### 3）改界面
`index.html` 是唯一的界面文件，`build.js` 只负责把数据内嵌进去：

```
node build.js              # 用 data.json 出 dist/太原空域频率图.html
node build.js zbsj.json    # 用别的包出 dist/zbsj.html
```

## 五、数据更新（每个 AIRAC 周期）

本期数据取自中国民航 eAIP 的 **EAIP 2026-12 (V1.3)** 数据包，
生效 2026-11-26 00:00（北京时间），失效 2026-12-24。
换周期时只需重新取 AD 2.18 / 2.19 / 2.17 与 ENR 2.1.3 / 2.1.5，按上面结构更新 JSON。

## 六、免责

数据供模拟飞行、学习与资料核对使用。真实飞行以现行有效 AIP/NAIP 与管制指令为准。
ILS 下滑台（GP）与指点标频率为机载接收频率，不可用于通话。
